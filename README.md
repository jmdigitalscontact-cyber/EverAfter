# EverAfter mockup

Static sales demo of the digital wedding suite. No PHP, no database, no login.

## Open it

Open [`index.html`](index.html) in a browser (double-click or Live Preview). Internet is needed only for fonts. Wedding photos are stored locally in `assets/photos/`.

## What’s inside

| File | What a client sees |
|------|--------------------|
| `index.html` | Product story, packages, design looks, links to every screen |
| `designs.html` | Five invitation identities (palette + sample couple) |
| `invitation.html` | Invitation site + private RSVP (look follows the header) |
| `admin.html` | Dashboard, invitations, export, seating, photos, votes, notes |
| `reception.html` | Phone app: lock → welcome → vote → seats, menu, gallery, notes, gifts |
| `wall.html` | Venue TV / projector POV slideshow |
| `offering.html` | Browser-ready offering brief |
| `OFFERING.md` | Markdown copy for proposals |

Use the **Look** menu on any screen to switch palettes. The same product is shown in:

1. **Sage Garden** — Sofia & Gabriel (forest green, cream, champagne)
2. **Champagne Blush** — Elena & Marco (dusty rose, ivory, gold)
3. **Midnight Velvet** — Camille & Dominic (navy, antique gold)
4. **Terracotta Olive** — Isla & Mateo (clay, olive, cream)
5. **Ivory & Ink** — Amara & Julian (charcoal, cream, gold italic)

These are sales samples, not live weddings.

## How to use on a sales call

1. Share `index.html` (or host the `mockup` folder).
2. Open **Looks** and let the couple pick a direction.
3. Walk Invitation → RSVP unlock → Admin (including export and notes) → Reception (lock, vote, seat search, gallery, gifts) → Photo wall.
4. Send `OFFERING.md` as the written scope.

The live product lives in the rest of this repository and is customized per couple.
